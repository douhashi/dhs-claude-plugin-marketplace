# テンプレート: 完了報告・PR 作成・打ち切り・エスカレーション

- **書き手**: オーケストレータ（implement / do スキル）
- **共通ルール**: [_rules.md](./_rules.md)

## `## PR 作成`（200 字）

```markdown
## PR 作成

PR: <PR URL>
```

## `## 完了報告`（500 字）

```markdown
## 完了報告

PR <PR URL> をマージし（`<merge commit sha>`）、本 Issue をクローズしました。

- 変更: （何をしたかを 1-2 文）
- 変更ファイル: N 件（`path/a.ts`, `path/b.ts`, ...）
```

実装内容の再掲は禁止。詳細は `## 実装内容` コメントと PR の diff にある。

## `## CI 修正打ち切り`（300 字）

```markdown
## CI 修正打ち切り

2 回の修正試行で CI を通せませんでした。フォローアップ Issue: <新規 Issue URL>

- 最終失敗: （失敗したチェック名とエラーの要点を 1-2 文）
```

## エスカレーション Issue の本文（500 字）

CI 修正を打ち切ったときに起票するフォローアップ Issue。通常の Issue 本文テンプレート
（[issue-body.md](./issue-body.md)）ではなく、以下を使う。

```markdown
元 Issue: <元 Issue URL>
元 PR: <PR URL>

## 試行内容

| 回 | 修正 | 失敗 |
|:--|:--|:--|
| 1 | （1 文） | （1 文） |
| 2 | （1 文） | （1 文） |

## 最終失敗

（失敗したチェック名とエラーの要点を 1-2 文）
```

CI ログの貼り付けは禁止。ログは PR の Checks から辿れる。
