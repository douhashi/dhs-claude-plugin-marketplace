# テンプレート: 未記載 Issue の検討

- **書き手**: sync-roadmap スキル（Phase 3 でユーザーと相談するとき）
- **用途**: ロードマップに載っていない Open Issue を一覧で示し、載せるかどうかを一緒に決める
- 決めるのはユーザー。スキルは叩き台を出し、質問に答え、決まった内容を反映する

## 一覧の雛形

```markdown
ロードマップに載っていない Open Issue が 4 件あります。

| # | Issue | 内容 | 案 | 位置・理由 |
|:--|:--|:--|:--|:--|
| 1 | #27 検索を高速化する | 検索が 3 秒かかる | 載せる | #24 の直後（同じ検索画面を触る） |
| 2 | #29 ログを整理する | 出力が多すぎて追えない | 載せる | 未完了行の末尾（依存なし） |
| 3 | #30 認証方式を見直したい | 方針が未決 | 載せない | 議論が要る |
| 4 | #12 CI の様子を調べる | 調査メモ | 載せない | 着手の対象ではない |
```

## 列

| 列 | 内容 | 上限 |
|:--|:--|--:|
| `#` | 通し番号（ユーザーが「1 と 3 だけ」と指せるようにする） | — |
| Issue | `#<番号> <タイトル>` | — |
| 内容 | Issue 本文を読んで、何の話かを 1 文 | 25 字 |
| 案 | `載せる` / `載せない` | — |
| 位置・理由 | `載せる` は追加位置とその根拠、`載せない` は理由 | 30 字 |

## 案の付け方

`載せる` の位置は `${CLAUDE_PLUGIN_ROOT}/templates/roadmap-pr.md` の「追加位置の決め方」に従う。

`載せない` の案を出すのは、次のような Issue。**判断の押し付けはしない。案であることを明示する。**

- 方針が決まっておらず、議論（`spira:brainstorming`）が先に要る
- 人の判断・作業が前提（契約、外部サービスの申し込み、デザインの確定など）
- 質問・調査メモなど、着手の単位になっていない
- 重複している、または古くて内容が現状と合っていない

`載せない` が案の Issue にも、載せる場合の位置を「追加位置の決め方」で決めておく（Issue ごとの問いの選択肢に使う）。

## 問い

一覧を出したら、`${CLAUDE_PLUGIN_ROOT}/templates/ask-user-question.md` の規則に従って `AskUserQuestion` で聞く。**回答なしに PR を作らない。**

### Issue ごとの問い

一覧の Issue ごとに 1 問。1 回の呼び出しに一覧の `#` 順で 4 件まで載せ、5 件以上なら 4 件ずつ続けて呼ぶ。

| 項目 | 内容 |
|:--|:--|
| `question` | `#<番号> <タイトル>` をロードマップに載せますか |
| `header` | `#<番号>` |
| `options` | `案の位置で載せる`（説明に位置を 1 文） / `載せない`（説明に理由を 1 文）。案の側を先頭にして `（推奨）` を付ける |

| ユーザーの応答 | 行動 |
|:--|:--|
| `案の位置で載せる` | その位置で `載せる` に決める |
| `載せない` | `載せない` に決める |
| `Other`: 位置の修正（「先頭に」「#24 の直後に」など） | 指定の位置で `載せる` に決める |
| `Other`: Issue の中身の質問 | 本文を読んで 3 行以内で答え、その Issue の問いだけを出し直す |

### 決まった内容の確認

全件の回答を反映した一覧を再掲し（案の列を決まった内容に置き換える）、次の問いを出す。

| 項目 | 内容 |
|:--|:--|
| `question` | この内容でロードマップの PR を作ってよいですか |
| `header` | `整理` |
| `options` | `PR を作る（推奨）`（`載せる` の Issue を PR にする） / `今回は載せない`（全件を載せずに報告へ進む） |

| ユーザーの応答 | 行動 |
|:--|:--|
| `PR を作る` | `載せる` は `${CLAUDE_PLUGIN_ROOT}/templates/roadmap-pr.md` の「整理」節で PR にする。`載せない` はロードマップに触れず、報告に理由とともに書く |
| `今回は載せない` | PR を作らない。全件を `載せない`（理由: 今回は見送り）として報告に書く |
| `Other`: 修正指示（「1 と 3 だけ」「#27 は先頭に」など） | 指示を反映して一覧を再掲し、この問いを出し直す |
