# テンプレート: ロードマップへの追加位置

- **書き手**: create-issue スキル（Phase 5）
- **用途**: 起票した Issue をロードマップのどこに入れるかを示し、PR を作る前に承認を得る
- 位置の決め方・行の書式・PR の書式は `${CLAUDE_PLUGIN_ROOT}/templates/roadmap-pr.md` が単一ソース

## 雛形

以下のコードブロックの中身をそのまま雛形として使う。

```markdown
| Issue | 追加する行 | 追加位置 | 理由 |
|:--|:--|:--|:--|
| #34 | `- [ ] **B5** 検索結果を絞り込めるようにする。 → #34` | #27 の直後 | #27 の検索画面が前提 |
| #35 | `- [ ] **C2** ログの出力先を設定できるようにする。 → #35` | 未完了行の末尾 | 依存も関連も無い |

この位置でロードマップに追加し、PR を作ってマージしてよいですか？
```

## 列

| 列 | 内容 | 上限 |
|:--|:--|--:|
| Issue | 起票した Issue の番号 | — |
| 追加する行 | ロードマップに挿入する行そのまま（`roadmap-pr.md` の「ロードマップの行」に従う） | — |
| 追加位置 | 隣の行の Issue 番号で示す（`#25 の直前`・`#24 の直後`・`未完了行の末尾`） | — |
| 理由 | 位置を決めた根拠を 1 文 | 30 字 |

## 記述ルール

- 起票した Issue は**すべて**表に載せる。載せない Issue を作らない
- 表の後には、承認を求める 1 文だけを添える
- 既存の行の並べ替え・文言の変更は提案しない

## 承認の扱い

| ユーザーの応答 | 行動 |
|:--|:--|
| 承認 | 表のとおりに追加し、PR を作ってマージする |
| 位置の修正指示 | 指示を反映して**表を作り直し**、再提示する。**承認を得るまで PR を作らない** |
| 追加しない | ロードマップを変更せず、報告に「ロードマップ未追加」と書く |
