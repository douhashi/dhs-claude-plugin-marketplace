## 記号

| 記号 | 意味 |
|:--|:--|

| ⏸ | 依存待ち（依存先の Issue が未完了） |
| 📝 | 計画中（`## 実装計画` 未記録） |
| 🛠 | 実装中（計画済み・PR 未作成） |
| 🧪 | CI 中（PR 作成済み・未マージ） |

| ⛔ | 人手対応待ち（Infisical の変数が未設定） |
| ⚠️ | 失敗（ラインが完了せずに終わった） |
