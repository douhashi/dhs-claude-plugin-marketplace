# テンプレート: キックオフ報告

- **書き手**: autopilot スキル（前提条件がすべて揃ったとき）
- 表は 1 行 1 事実。説明文は足さない
- 着手見込みは `spira:pick` の優先順（整理後のロードマップの並び）で上から並べ、依存が未完了のものは `待ち` とする
- ロードマップのずれを直した場合は、前提条件の後に「ロードマップの整合」節を出す。ずれが無かった場合は節ごと省く
- ロードマップを整理した場合は、着手見込みの前に「ロードマップの整理」節を出す。整理が不要だった場合は節ごと省く
- 対象外にした Issue は「ロードマップの整理」節にだけ載せ、着手見込みの表には載せない
- 着手見込みの表には Open Issue をすべて載せる。`escalated` Issue は表の末尾に置き、`🆘` を付けて見込みを `対象外（人手対応）` とする

````markdown

### 開始方法

1. `/clear` を実行する
2. 次のプロンプトを実行する

```
.tmp/spira-autopilot/context.md を読み、「メインセッションの進め方」に従って自走開発のイテレーションを進めてください。
```

ラインの経過は、別の端末で次を実行すると全ライン分まとめて流れます（Ctrl-C で終了）。

```bash
<spira>/scripts/watch-lines.sh <ルート>/.tmp/spira-autopilot/lines
```

止めたいときは「止めて」と伝えてください。走っているラインは最後まで進み、新しいラインは起動しません。
````

閲覧コマンドの `<spira>` は `${CLAUDE_PLUGIN_ROOT}` の、`<ルート>` はルートの展開後の絶対パスにする。

シークレットの置き場所の行は、`.env` で代替した場合は `✅ .env`、
必要なシークレットが 0 件で検査を飛ばした場合は `— 不要（必要なシークレット 0 件）` とする。
0 件の場合、人の手による準備物の行は `✅ 0 件` とする。

`.tmp/` が git に無視されていない場合は、前提条件の表の下に次の 1 行を足す。

```markdown
⚠️ `.tmp/` が `.gitignore` に入っていません。コミットに混ざらないよう追加を検討してください。
```

ロードマップのずれを直す PR がマージできなかった場合は、「ロードマップの整合」節を次に差し替える。

```markdown
### ロードマップの整合

⚠️ 整合修正 PR #35 がマージできませんでした。ずれていた 2 件（#18・#20）は自走の終わりの整合修正で再び拾います。
```

ロードマップを整理できなかった場合は、「ロードマップの整理」節を次のいずれかに差し替える。

```markdown
### ロードマップの整理

⚠️ ロードマップがありません。着手順は Issue 番号の若い順になります。
```

```markdown
### ロードマップの整理

⚠️ 追加 PR #36 がマージできませんでした。未記載の 2 件（#27・#29）は番号順で拾われます。
```
