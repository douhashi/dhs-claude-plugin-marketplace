## 節

| 節 | 内容 |
|:--|:--|
| 構成 | 提案の「構成」をそのまま移す。追加モードでは既存の表に行を足し、既存の行は変えない |
| 配布先 | 提案の配布先と判定の根拠。Web / API のセットを使わなければ「なし」 |
| 共通レイヤー | 複数セットにまたがるときだけ埋める。セットが 1 つなら「なし」 |
| 運用先に求める前提 | setup エージェントが自分で用意できないもの。環境変数は名前だけを書き、値を書かない |
| 出典 | 提案の「調査結果」のうち、構成に載せた要素の版・出典・確認日 |

## 記述ルール

- 1 項目 1 文。検討の経緯・不採用にした候補・導入手順・コード例を書かない
- 版は「出典」の節にだけ書く。出典で確かめていない版を書かない
- 用語はリポジトリと各技術の公式ドキュメントにある語を使い、独自の略語・造語・比喩を使わない
